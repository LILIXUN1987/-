# 模块六：站内信 + 询价推送

## 一句话卖点
**客户询价直接推送到站内信+邮件，一条都不会漏。**

## 推送链路

```
客户搜索 → 5要素齐全(始发港+目的港+件数+重量+体积)
    ↓
系统自动匹配你的推广
    ↓
📧 你收到站内信：「有群友发布货物求购…」
📨 你收到邮件：「您有新的询价 - XX航线」
    ↓
你打开站内信，查看客户需求
    ↓
直接回复客户，沟通报价
```

## 为什么用站内信不用微信

| 微信 | 平台站内信 |
|------|-----------|
| 客户加你好友需要通过 | 系统自动匹配，不需要加好友 |
| 客户可能在睡觉/不方便 | 邮件同步通知，24小时都能收 |
| 不知道客户来路 | 系统匹配的询价，客户需求清晰 |
| 多个客户分不清 | 站内信自动分组，按对话排列 |

## 邮件提醒

```
现在还会自动发邮件到你的注册邮箱：
💬 您收到了一条新消息 - XXX公司
  用户 XXX 给您发了一条消息：
  「请问广州-LAX还有仓位吗？」
  ┌─────────────┐
  │ 进入收件箱回复 │
  └─────────────┘
```

> 注意：只有**首次对话**才会发邮件通知。
> 如果你已经和客户聊上了，后续消息不发邮件，不打扰你。

## 话术

> 陈总，你的推广信息发布之后，
> 有客户搜到你的航线，如果填了件数重量，
> 系统会自动推送到你的收件箱，还会发邮件通知你。
>
> 你打开站内信就能回复客户，
> 不用加微信、不用打电话，客户就在那等着你报价。
>
> 而且你也不用一直盯着手机，
> 邮件通知到了再上平台回复都来得及。
