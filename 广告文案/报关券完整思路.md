# 🎫 报关券 · 从源头到使用的完整思路

## 一句话总结

**利用行业深耕多年的优势报关资源，通过19.9月费+券模式放大价值。**

---

## 一、源头 — 报关行资源

### 前提条件
你（平台运营方）在行业多年，手里有低价可靠的报关资源。

| 资源 | 举例 |
|------|------|
| **合作报关行** | 广州白云机场 50元/票（市场价100-150） |
| **结算价** | 票面实结 50元/票 |
| **服务范围** | 9:00-21:30 均可申报 |
| **日接单上限** | 50票/天（有备选报关行） |

> 关键是：这些资源过去因为客户量不够，利用率很低。
> 社区要做的就是：**把这些资源打包成券，通过货代分发出去。**

---

## 二、分发 — 货代19.9月费

### 核心设计

```
货代每月付 19.9 元
       ↓
获得 1 张面值 50 元的报关券
       ↓
券不能自己用，只能转赠给社区内的外贸用户
       ↓
外贸收到券后，可用于抵扣报关费
```

### 为什么货代愿意付？

| 货代心理 | 说明 |
|---------|------|
| 19.9 没有决策成本 | 一顿快餐钱，试试也不亏 |
| 送券=维护客户关系 | 比请吃饭体面，客户觉得货代靠谱 |
| 不认识的外贸也送 | 反正不认识，送了也不亏，说不定拓客 |
| 取消月费=断了客户连接 | 客户每月收券习惯了，取消不好交代 |

### 送券方式（盲盒式）

```
货代打开送券页面 → 看到外贸活跃列表（公司名/搜索次数/询价次数）
                 → 自主选择一位外贸 → 点击「送券给TA」
                 → 外贸收到通知：「XX货代送您一张50元报关券」
                 → 货代同步收到站内信：「券已送达」
```

> 不需要货代输入客户手机号，解决了"怕客户跑了"的心理障碍。

---

## 三、使用 — 外贸零元报关

### 券的价值

```
外贸直接找报关行：市场价 50元/票（如果知道联系方式）
外贸用社区券：    0元（券面值50全额抵扣）

差额 = 50元，这就是券给外贸的实惠。
```

### 为什么不怕外贸绕过平台？

```
这是个阳谋：

外贸知道报关行联系方式 →
  下次直接找报关行 → 付50元
  用社区券         → 付0元

只要外贸手上有券，他就没有绕过平台的动力。
因为每次绕开 = 多付50元。

没券了怎么办？→ 让货代续费继续送。
外贸会反过来催货代：「你的券呢？快续费啊！」
```

---

## 四、盈利 — 20%使用限额 + Breakage

### 核心风控

**每月全平台限使用 20% 的券（先到先得）。**

### 算账

```
假设 1,000 个货代订阅：

月费收入： 1,000 × 19.9 = 19,900 元
发出券：   1,000 张
月使用上限：200 张（20%）
结算给报关行：200 × 50 = 10,000 元
━━━━━━━━━━━━━━━━━━━━━━━━━━━
月净利润： 9,900 元 ✅
年净利润： ≈ 118,800 元
```

### 为什么 20% 够用？

| 原因 | 说明 |
|------|------|
| **使用链路很长** | 发券→货代想起送→外贸收到→有货要报→使用，中间每一步都会流失 |
| **券会累积** | 用户手里券越积越多，越舍不得取消月费 |
| **外贸不急用** | 小单不用报、近期没货、忘记用了…自然产生 breakage |
| **超出排队** | 每月200张用完，下月优先补上，不影响用户体验 |

### 这就是阳谋

```
低月费 19.9 → 货代先付了再说
       ↓
20% 限额  → 不是不让用，是慢慢用
       ↓
拖延 = 自然产生 breakage（未用券）
       ↓
breakage 覆盖了券面值和月费之间的差价
       ↓
平台利润出来了，但每一方都不觉得自己亏了 ✅
```

## 六、关键提醒

- **不需要隐藏报关行联系方式** — 券的50元差价就是最好的护城河
- **不要硬拉用户注册** — 通过送券自然引流，货代是推广员
- **20%限额是利润的生命线** — 低于此比例利润更高，高于此比例可能亏钱
- **首月免费试用** — 让货代零门槛体验，后续自动续费

> **这不是套路，是阳谋。**
> 规则全部公开，但每一方算完账，发现自己确实不亏。
> 这就是好商业模式的样子。
