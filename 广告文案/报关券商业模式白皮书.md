# 🎫 报关券商业模式白皮书

## 一句话说清楚

**货代每月付 19.9 元 → 获得 1 张报关券 → 转赠给外贸客户 → 外贸客户可用券抵扣报关费 → 报关行在实际服务后收款。**

---

## 💡 核心洞察

这套模式本质是：

> **健身房会员卡的逻辑，但每一方都不觉得自己亏了。**

| 类比 | 健身房 | 报关券 |
|------|--------|--------|
| 付费 | 年费两千，去了才值 | 月费19.9，送了才值 |
| 拖延 | 交了钱不去，健身房赚了 | 20%使用上限，慢慢用 |
| Breakage | 大部分会员去了几次就不去了 | 大部分券不会当月用完 |
| 结果 | 健身房靠"不去的人"赚钱 | 平台靠"未用的券"覆盖成本 |

**和健身房不同的地方 —— 这是阳谋，不是套路：**

- 货代确实拿到了 **可以送给客户的东西**（维护关系）
- 外贸确实拿到了 **可以省钱的券**（即使没当月用，下个月还有额度）
- 报关行确实 **零风险接单**（有单才结算）
- 平台赚的是 **低月费 + 20%限额 → 自然产生的 breakage**

```
低月费 → 降低决策门槛，让货代先付了再说
   ↓
20%限额 → 不是不让用，是慢慢用
   ↓
拖延 = 自然产生 breakage（未用券）
   ↓
breakage 覆盖了券面值和月费之间的差价
   ↓
利润出来了，四方共赢
```

## 一、为什么做这个

### 行业的痛点

| 问题 | 现在的情况 |
|------|-----------|
| **货代留不住客户** | 外贸公司换货代像换衣服，没有绑定机制 |
| **外贸公司痛点** | 报关费100-150/票，小单利润薄 |
| **报关行找客难** | 低价也难获客，靠关系吃饭 |
| **社区缺商业模式** | 免费工具用了就走，没有收入 |

### 我们的解法 —— 报关券

```
货代月费 19.9 → 获得报关券 → 转赠给客户 → 客户使用 → 社区结算给报关行
      ↓              ↓              ↓            ↓
  稳定收入       送礼理由       绑定客户      只有实际服务才付款
```

## 二、各方获益

### 🏢 货代（月费 19.9 元）

| 获益 | 说明 |
|------|------|
| **有了送礼的理由** | 给客户送一张报关券，比请吃饭体面、专业 |
| **绑定客户** | 客户注册社区后，下次找别的货代成本变高 |
| **成本极低** | 19.9元/月，一顿快餐钱 |
| **月费自动续费** | 不需要每次手动操作 |

> 货代视角：我不是在花钱买服务，我是在花钱维护客户关系。

### 🏭 外贸公司（免费使用）

| 获益 | 说明 |
|------|------|
| **免费获得报关券** | 货代送的，不用自己花钱 |
| **抵扣报关费** | 每票省50-100元，积少成多 |
| **多一个货代选择** | 社区里有大量货代可以比价 |

### 🚛 报关行（零风险接单）

| 获益 | 说明 |
|------|------|
| **零成本获客** | 不用自己找客户，社区推单给你 |
| **零坏账风险** | 社区担保结算，不会跑单 |
| **有单再接** | 只有实际报关才收钱，不做亏本买卖 |
| **确定性收入** | 接一票算一票，没有拖欠 |

### 🌐 社区平台

| 获益 | 说明 |
|------|------|
| **月费收入** | 19.9元/月 × N个货代，稳定现金流 |
| **Breakage 利润** | 发出的券不一定全部使用，未使用的券收入归平台 |
| **双边网络效应** | 货代为了送券拉客户注册，两边一起增长 |
| **数据积累** | 知道谁在报关、什么货、多少量 |

## 六、关键数据预测

### 核心风控规则：当月使用上限 20%

为防止结算成本超过月费收入，系统自动控制**每月只有 20% 的券能被使用**（先到先得）。这不仅保证了利润，也让报关行的接单量稳定可控。

### 假设 1,000 个货代付费

| 项目 | 计算 | 月收入 |
|------|------|--------|
| 月费收入 | 1,000 × 19.9 | **19,900 元** |
| 发出报关券 | 1,000 张/月 | — |
| 月使用上限 20% | 200 张/月 | — |
| 结算给报关行 | 200 × 50元 | **-10,000 元** |
| **月净利润** | — | **9,900 元 ✅** |
| **年净利润** | — | **≈ 118,800 元** |

### 如果增长到 5,000 个货代

| 项目 | 计算 | 月收入 |
|------|------|--------|
| 月费收入 | 5,000 × 19.9 | **99,500 元** |
| 月使用上限 20% | 1,000 张/月 | — |
| 结算给报关行 | 1,000 × 50 | **-50,000 元** |
| **月净利润** | — | **49,500 元 ✅** |
| **年净利润** | — | **≈ 594,000 元** |

### 20% 上限的隐藏收益

```
用户手里券越积越多，越舍不得取消月费
↓
取消月费 = 失去所有未使用的券
↓
用户留存率天然提高
```

### 如果未来调整月费或比例

| 月费 | 20%上限 | 月净利（1,000人） | 月净利（5,000人） |
|------|---------|-----------------|-----------------|
| 19.9 | 20% | 9,900 | 49,500 |
| 29.9 | 20% | 19,900 | 99,500 |
| 19.9 | 15% | 12,400 | 62,000 |
| 19.9 | 25% | 7,400 | 37,000 |

## 七、为什么报关行愿意加入

### 对比传统获客方式

| 方式 | 成本 | 风险 |
|------|------|------|
| 业务员跑口岸 | 人工 + 差旅 | 不一定有单 |
| 朋友介绍 | 人情债 | 不稳定 |
| 电话销售 | 低效 | 被拉黑 |
| **接入社区报关券** | **零成本** | **零风险** |

### 给报关行的承诺

> "你不需要预付一分钱，不需要做任何推广。只要在社区注册，告诉我们你能服务的口岸和价格。有单了我们会派给你，你完成了服务我们才结算。"

## 八、风险控制

| 风险 | 对策 |
|------|------|
| 货代和外贸私下交易绕过平台 | 券不显示报关行联系方式，使用时通过平台生成单号，报关行无单号不服务 |
| 外贸注册后不用 | 不影响，月费已收，券不用就是breakage利润 |
| 报关行服务质量差 | 引入评价体系，差评多的报关行减少派单 |
| 月费续费意愿低 | 19.9 无感定价，券送出去后客户会提醒货代续费 |

## 九、一句话总结

**报关券模式 = 货代花 19.9 维护客户关系 + 外贸免费报关 + 报关行零成本接单 + 平台收月费赚 breakage**

四方共赢，每一方都不觉得自己亏了。
