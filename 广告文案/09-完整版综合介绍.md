## 这是一个什么平台？

简单说：**共享物流社区。**

- 如果你是**货运代理** → 发布舱位信息，客户搜港口找到你
- 如果你是**外贸客户** → 查舱位、比价格、联系货代
- 如果你是**律师** → 提供法律咨询，对接行业需求

---

## 货代为什么需要加入？

### 第一，推广不再靠刷屏

```
以前：每天在10个群发同样内容 → 被聊天刷上去 → 没人看
现在：在系统录一次 → 客户搜港口就能看到 → 自动匹配

你只需要花30秒输入：
「广州-LAX 下周大仓位 2000KG 5元/KG」
AI自动解析入库，全天候展示。
```

### 第二，客户主动来找你

```
外贸客户打开「空运查询助手」
输入「深圳-LAX」
→ 你的推广信息出现在他面前

如果他填了件数+重量+体积
→ 系统自动推送到你的站内信+邮件
→ 你打开就能回复报价
```

### 第三，数据告诉你效果

```
你的「我的推广统计」：
→ 这条航线被看了多少次
→ 收到了几个询价
→ 哪个航线转化率最高

不用再盲打了，数据说话。
```

### 第四，企业认证建立信任

```
上传营业执照 → 管理员审核 → 🏢 认证企业
客户一看：这家公司有认证，靠谱！
询价率至少翻一倍。
```

### 第五，行业黑名单保护你

```
「吐槽专区」共享不诚信合作方信息
≥2家投诉同一公司 → 全员避雷警告
好货代在这个平台更受信任。
```

### 第六，邀请同行有奖励

```
你的推荐码 → 发给同行 → 对方注册
→ 你的体验期延长（最多+7天）
→ 对方也额外+2天
```

## 适合什么样的货代？

| 类型 | 为什么适合 |
|------|-----------|
| **做空运/海运/陆运的** | 每个品类都有独立查询入口 |
| **有固定航线的** | 录入一次，有需求的客户持续看到 |
| **想拓展客户的** | 外贸客户主动搜港口，精准获客 |
| **想建立口碑的** | 企业认证+实名，可信度高 |
| **不想天天刷群的** | 录一次管一天，客户自己找过来 |

## 怎么加入？

```
1. 打开 http://localhost:5173/register
2. 选择「货运代理」身份
3. 填写信息 → 上传名片 → 提交审核
4. 审核通过后开始发布推广
```

**或者更简单：** 找管理员直接开通，你邮箱收通知就行。
