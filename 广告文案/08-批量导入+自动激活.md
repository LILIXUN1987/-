# 模块八：批量导入名片 + 自动激活

## 一句话卖点
**展会收了 100 张名片？Excel 导入，系统自动创建账号 + 发邮件通知，不用手动注册。**

## 场景：展会收了一堆名片

```
你参加物流展，收了 80 张货代名片。
以前：一张一张手动注册，每张要填邮箱验证码，累死。
现在：
```

## 操作流程

```
① 打开「导入名片」页面
② 下载 Excel 模板
③ 把名片信息填进去：
   | 姓名 | 公司名 | 手机号 | 邮箱 |
   | 张总 | XX物流 | 138xxx | z@xx.com |
④ 上传 Excel → 系统自动创建 80 个账号
⑤ 每个邮箱自动收到开通邮件：
   「您的 123 共享外贸物流社区 账号已开通」
   「用户名：XXX」「密码：Ab3x9k」
```

## 自动跟进

```
导入后系统自动工作：
  ✓ 账号创建 ✅
  ✓ 邮件发送 ✅（含用户名密码）
  ↓ 3 天后未登录
  ✓ 再次提醒邮件：「您的账号已开通，快来体验吧！」
  ↓ 之后每 7 天
  ✓ 持续提醒一次
```

## 话术（展会主办方/协会合作）

> 王总，你们协会的货代会员如果需要批量入驻，
> 你把会员名单发给我，Excel 就行，
> 我一次性全部开通，自动发邮件通知每个人。
> 
> 省去你自己一个一个注册的麻烦，
> 也省得你还要微信通知每个人来注册。
> 
> 系统自动跟进，3天后没登录的还会再发邮件提醒，
> 你不用操心。

## 对货代个人的话术

> 你去展会收的名片，不用一个一个手动注册。
> 把名片信息整理成 Excel，上传到平台，
> 系统自动帮他们创建账号并发邮件通知。
> 
> 他们收到邮件就能直接登录使用，
> 不用你再挨个通知。
