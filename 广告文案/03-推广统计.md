# 模块三：我的推广统计

## 一句话卖点
**你发的每一条推广，有没有人看、有没有人问，数据说话，不再盲打。**

## 痛点
- 在群里发了广告，不知道有没有人看
- 客户到底是搜什么找到你的？不清楚
- 哪条航线询价最多？凭感觉

## 平台数据面板

```
┌────────────────────────────────────────┐
│  📊 我的推广统计                       │
│                                         │
│ 推广总数  │ 有效推广  │ 累计浏览  │ 累计询价 │
│    28     │   22     │   156     │   12    │

│                                         │
│  航线维度分析（按浏览量排序）            │
│  广州-LAX    46次  3询价  ➜ 6.5%       │
│  深圳-SGN    32次  2询价  ➜ 6.3%       │
│  上海-FRA    18次  1询价  ➜ 5.6%       │
└────────────────────────────────────────┘
```

## 货代看到什么
- **推广总数** — 你一共发布过多少条推广
- **有效推广** — 还在有效期内的（没过期）
- **累计浏览** — 多少客户看过你的信息
- **累计询价** — 多少客户通过系统询价
- **航线转化率** — 哪条线询价最多，重点投入

## 现场话术

> 王总，你之前不是问我"发这个有没有用"吗？
> 你看这个「我的推广统计」——
> 你今天发了一条广州-LAX，这周累计被看了 46 次，
> 收到了 3 个询价，转化率 6.5%。
> 
> 哪个航线询价多，哪个航线没人看，数据一目了然。
> 不用再盲打了。
