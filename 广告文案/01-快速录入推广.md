# 模块一：快速录入推广信息

## 一句话卖点
**不用再在微信群里刷屏了，录一次管一天，客户搜港口自己找上门。**

## 痛点场景
- 每天早上在 10 个微信群复制粘贴同样的特价信息
- 发完半小时被聊天刷上去，根本没人看
- 客户问"你家有美线吗"，你翻半天朋友圈才找到上次发的报价

## 平台解决方案

| 以前 | 现在 |
|------|------|
| 微信群刷屏 → 被忽略 | 系统录一次 → 全天展示 |
| 客户搜不到你的信息 | 客户搜港口代码 → 自动匹配你的推广 |
| 发完就没了 | 每晚20点自动清除，次日重新录入最新价格 |
| 手动编辑排版 | AI 自动解析：输入自然语言 → 结构化入库 |
