# 模块七：推荐裂变系统

## 一句话卖点
**邀请同行加入，你的免费体验期无限延长。**

## 推荐奖励规则

| 推荐人数 | 奖励天数 | 等级 |
|---------|---------|------|
| 1~2 人 | +3 天 | 🌱 |
| 3~5 人 | +5 天 | 🥉 |
| 6 人+ | +7 天 | 🥇 每多一个继续再加 |
| 新用户通过链接注册 | 额外 +2 天（双边奖励） | 🎁 |

## 推荐入口

```
每个用户都有一个专属推荐链接：
http://localhost:5173/register?ref=RFXXXXXX
                                  ↑
                           你的6位推荐码

可以在「个人信息」页查看自己的推荐码和奖励记录。
```

## 操作步骤

```
1. 打开平台 → 看自己的推荐码
2. 复制推荐链接 → 发给同行微信/群
3. 对方通过你的链接注册
4. 你的体验期自动延长
5. 对方也额外获得 2 天
```

## 话术

> 刘总，邀请同行加入还能延长试用期。
> 你复制你的推荐链接发到同行群里，
> 有人通过你的链接注册了，系统自动多送你几天使用时长。
>

> 对方也能多拿 2 天，双赢。
