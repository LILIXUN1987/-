## 1. 系统概览

### 1.1 定位

**123共享外贸物流社区** 是国际物流行业首个全角色协作平台。货代、外贸、海外代理、报关行、律师、检测认证、运输保险、管理员八个角色在同一平台内互通协作。

### 1.2 注册与试用

| 角色 | 试用期 | 月费 | 核心功能 |
|------|--------|------|----------|
| 货代 Forwarder | 30天免费 | ¥19.9/月 (标准) / ¥49.9/月 (专业) | 发布舱位、获取询价、报关券 |
| 外贸 Trader | 永久免费 | 无 | 搜索舱位、收报关券、询价 |
| 海外代理 Overseas Agent | 30天免费标准版 | 标准版免费 / 升级付费 | DDP服务、对接中国货代 |
| 报关行 Broker | 永久免费 | 无 | 投放券、核销券、黄页展示 |
| 律师 Lawyer | 永久免费 | 无 | 法律咨询、个人主页 |
| 检测认证 Inspector | 30天免费 | 后续订阅 | 服务展示、在线咨询 |
| 运输保险 Insurer | 30天免费 | 后续订阅 | 服务展示、在线咨询 |
| 管理员 Admin | — | — | 全系统管理 |

### 1.3 注册流程

```
访客打开首页 → 选择身份 → 填写注册信息
  ├─ 外贸：姓名 + 公司名 + 邮箱 + 密码
  ├─ 货代/律师/检测/保险：上述 + 上传名片 + 手机号
  ├─ 海外代理：英文界面 + 公司名 + 邮箱 + 密码
  ├─ 报关行：先注册用户 → 登录后创建报关行档案
  └─ 管理员：由其他管理员手动创建

注册成功 → 邮箱验证码激活 → 登录 → Dashboard
```

## 2. 八个角色详解

### 2.1 🚢 货代 (Forwarder)

**侧边栏入口：** Dashboard / 收件箱 / AI问答 / 发布舱位 / 开通月费 / 报关券 / 报关行 / 询盘管理 / 客户关系 / 我的发布 / 常往来合作商 / 成为危险品代理 / 各黄页目录

#### 2.1.1 发布舱位与特价

```
方式一：AI 智能录入
  粘贴自然语言文本 → AI 解析为结构数据 → 存入 cargo_spaces 表
  示例输入："CAN CZ SGN 仓位4号起 10CBM 500KG 普货 3.5/KG USD"
  
方式二：手动录入
  填写表单：始发港 / 目的港 / 航司代码 / 体积 / 重量 / 价格 / 有效期

方式三：API 批量导入
  POST /api/cargo-spaces/batch-import
  支持 JSON 数组，最多5000条/次
  mode=replace 先清空再导入，mode=append 追加
```

**查重机制：**
- 同一天同一人相同文本 → 自动合并
- 30天内相同航线+相同价格 → 提示已存在

**分类体系：**
- 空运出口 / 空运包税出口 / 海运出口 / 海运包税出口 / 陆运出口 / 快递出口 / 进口清关

#### 2.1.2 获取询价

```
外贸用户搜索航线 → 系统匹配货代发布的舱位
  ├─ 始发港/目的港匹配 → 站内信推送需求
  ├─ 5要素齐全(港+件+重+体) → "精准需求"标记
  └─ 同时邮件通知发布者（如果开启 notify_inquiry_email）
```

#### 2.1.3 报关券管理

```
开通月费订阅 → 自动从券池领取一张券 → 赠送给外贸客户
  券状态流转：issued（持有） → sent（已赠送） → used（已核销）
  
每月凌晨2:00 cron自动续发一张 ¥50 券
货代视角统计：现存可送 / 已送出 / 已核销 / 已过期
```

#### 2.1.4 客户关系

- **我的发布** — 查看自己发布的舱位数据，含浏览量、询价量
- **客户关系** — 查看谁看过/询过自己的推广
- **常往来合作商** — 收藏的报关行、海外代理、危险品代理快速联系
- **数据看板** — 7天浏览趋势、航线维度转化分析

#### 2.1.5 企业认证

上传营业执照 → 管理员审核 → 获得 🏢 认证企业标识 → 搜索结果中展示

### 2.2 🌏 外贸 (Trader)

**侧边栏入口：** Dashboard / 收件箱 / AI问答 / 查舱位 / 报关行 / 我的券包 / 各黄页目录

#### 2.2.1 搜索舱位

```
方式一：分类查询
  选择"空运出口" → 输入港口/航线 → 系统匹配货代发布的舱位
  搜索词自动扩展：中文地名↔IATA代码↔国家名↔英文地址

方式二：快捷询价
  填写：始发港 / 目的港 / 货物描述 / 件数 / 重量 / 体积
  系统自动推送给匹配的货代

方式三：快递实时询价（平台自营）
```

**搜索结果中可看到：**
- 航线、航司、有效期、发布者公司名
- 🏢 认证企业标识、🆕 新手上路标识
- 信任信号：共同代理、推荐关系、同公司、评分

**未登录用户：** 可浏览但隐藏联系方式（防爬）

#### 2.2.2 报关券使用

```
收到货代赠送的券 → 券包中可见 → 选择报关行使用
  填写报关信息 → 提交 → 券状态变为 used
  → 货代收到通知 → 报关行看到待处理订单 → 核销完成
```

每个外贸每月最多收到3张券（防轰炸）。

#### 2.2.3 免费次数限制

未登录/免费版每日搜索用户上限3次。基于 `search_logs` 表计数。

**侧边栏入口：** 工作台 / Dashboard / 公司主页 / 检测 / 保险 / 工具箱 / 收件箱

#### 2.4.1 入驻流程

```

  填写：公司名 / 口岸 / 运输方式(海运/空运/双选) / 报关费 / 服务承诺

```

```
  面值选择：¥20 / ¥30 / ¥50
  张数：1-1000
  运输方式：海运 / 空运
  口岸：从档案自动填充

券入池后 → 货代订阅月费时自动领取 → 赠送给外贸 → 外贸使用 → 报关行核销
```

#### 2.4.3 核销流程

```
方式一：外贸在线使用券
  外贸提交报关信息 → 报关行在"待处理订单"中看到 → 完成报关并确认 → 核销记录入库

方式二：手动核销
  报关行输入券号 + 报关单号 → 线下核销后补录
```

#### 2.4.4 评价体系

```
客户使用券后 → 可对报关行评分（服务/效率/有无问题）
  → 综合评分影响黄页排名
  → 回头客自动追踪
```

## 3. 核心功能模块

### 3.1 AI 智能解析

**端点：** `POST /api/cargo-spaces/parse-text`

```
用户粘贴文本 → DeepSeek API 解析
  → 提取：始发港/目的港/航司代码/体积/重量/价格/币种/货物类型
  → 自动入库 cargo_spaces 表
```

**港口代码映射：**
- 中文城市名 → IATA三字码（如"厦门"→"XMN"）
- 英文城市名 → IATA三字码（如"Los Angeles"→"LAX"）
- 国际汉字地名 → IATA三字码（如"首尔"→"ICN"）
- 国家名 → 该国所有机场代码（如"越南"→SGN,HAN,DAD...）

数据源：210个国内机场 + 688个国外机场 + 1300+英文名映射。

### 3.2 搜索即匹配

**端点：** `GET /api/cargo-spaces?category=空运出口&keyword=CAN SGN`

```
搜索流程：
1. 关键词拆解 → 机场代码+城市名+国家名+英文地址
2. 分类为始发港词（中国大陆+港澳）和目的港词（国外）
3. 分类分法：IATA代码→mainlandCode()判断，中文名→isMainlandCity()判断
4. 数据库查询：status=available AND notes LIKE '%【空运出口】%'
   AND origin_port LIKE '%始发港词%' AND dest_port LIKE '%目的港词%'
5. 按 origin_port+dest_port+airline_code 去重
6. 注入企业认证状态 + 信任信息 + 浏览量统计
```

**需求推送（5要素齐全时）：**
```
关键词含"件数+重量+体积+始发港+目的港"
  → 查 raw_messages 表中匹配的发布者
  → 通过站内信推送需求原文
  → 通过邮件通知发布者
  → 记录 search_logs（触发推送标记 has_push=true）
```

### 3.3 报关券生态

```
┌──────────┐   投放券    ┌──────────┐   订阅领取   ┌──────────┐
│  报关行   │ ────────→ │  券池    │ ────────→  │  货代    │
│ (Broker) │           │ (Pool)   │            │(Forwarder)│
└──────────┘           └──────────┘            └─────┬────┘
     ↑                                               │
     │ 核销                                           │ 赠送
     │                                               ↓
     │                                         ┌──────────┐
     └──────────── 使用报关 ─────────────────── │  外贸    │
                                               │ (Trader) │
                                               └──────────┘
```

**券状态机：**
```
issued → sent → used
  ↓        ↓
expired  expired
```

**定时任务：**
- 每天 02:00：为 active 订阅用户发放本月券
- 每天 01:00：标记超过2个月的 issued/sent 券为过期
- 每天 03:00：标记超过30天未核销的 sent 券为过期

### 3.4 信用分体系

**公式（0-100分）：**

| 项目 | 分值 | 说明 |
|------|------|------|
| 基础分 | +50 | 注册即可获得 |
| 评价分 | +0~30 | avgRating/5 × 30（无评价给+10） |
| 合作分 | +0~25 | 每次确认合作 +0.5，封顶25 |
| 争议扣分 | -15/次 | 每笔确认的争议扣15分 |
| 名片认证 | +10 | 上传并通过认证 |
| 注册满1年 | +5 | 忠诚奖励 |

**等级：**
- ≥90：⭐⭐⭐⭐⭐ 行业金口碑
- ≥75：⭐⭐⭐⭐ 非常可靠
- ≥60：⭐⭐⭐ 信誉良好
- ≥40：⭐⭐ 基础可信

### 3.5 DDP 到门服务

```
中国货代 → 在 DDP 页面搜索海外代理 → 发起询价
  海外代理 → 收件箱收到 DDP 询价 → 提交结构化报价
    中国货代 → 查看报价 → 选择合作 → 登记合作记录
      双方确认 → 信用分更新
```

**报价结构：**
- 始发港 → 目的港
- 运输方式（空运/海运/快递）
- 货物描述 / 件数 / 重量 / 体积
- 单价 / 总价 / 币种
- 有效期

### 3.6 争议调解

```
用户发起争议 → 填写：被投诉方 / 标题 / 详细描述
  → 管理员介入 → 审查 → 裁决或驳回
    → 裁决生效 → 责任方信用分 -15
```

**争议状态：** pending → under_review → resolved / dismissed

### 3.7 危险品代理黄页

危险品货代可注册为 DG Agent → 出现在黄页中 → 其他用户可搜索查看

**知识库：** UN编号速查、危险品分类、运输案例、FAQ

### 3.8 展会通讯录

名片拍照 OCR 识别 → 自动入库 → 按公司/姓名/角色搜索 → 一键导入系统

### 3.9 站内信系统

**功能：**
- 一对一私聊
- 文件附件支持
- 已读/未读状态
- 对话搜索
- 对话删除
- 评价对方

**通知机制：**
- 新消息 → 浏览器 Push 推送
- 首次对话 → 邮件通知
- 开启 notify_all_messages_email → 每条都邮件通知

### 3.10 工具集

- **体积重量计算器** — 空运(÷6000) / 快递(÷5000)
- **机场三字代码查询** — 210国内 + 688国外
- **HS编码查询** — 常见品类速查


### 5.2 邮件通知

| 事件 | 收件人 | 内容 |
|------|--------|------|
| 注册验证码 | 新用户 | 6位验证码 |
| 需求推送 | 匹配的货代 | 外贸需求详情 |
| DDP询价 | 海外代理 | 询价详情 |
